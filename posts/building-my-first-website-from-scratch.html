Building My First Website From Scrath

10/19/2026

The Portfolio Website

In this module, I learned HTML and CSS. I learned a lot in this module. This was the first module where I really learned something entirely new. And I think it's the one I had the most fun doing because it scratched the artist brain in me. Learning the basic HTML and CSS styling wasn't too hard thanks to Kevin Powell's YouTube videos on the subject. If anyone is wanting to learn, I'd recommend those videos for sure.

It started slow. getting 'Hello World' to show up on an html file. Then adding paragraphs, headers, and such. By the end of it though, I was sketching out layouts and color themes in Clip Studio to get a portfolio site of my own up and running. Obviously, it worked out pretty well, since you're reading this.

With all the documentation, it wasn't to hard to figure out what to do for different features and such, but learning to use media queries was a learning curve. And remembering the difference between a class and id was a bit hard at first. But funnily enough, I think I had the hardest time figuring out how to center various elements on the webpage or under other elements.

What's Next

The next blog post will be on module 3: Javascript. Taking everything I learned previously about programming and web design into a new language and making a browser-based game as well as learning how to fetch from an API and display it.
